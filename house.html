How the coordinates work

SVG puts the origin (0, 0) at the top-left corner. x grows to the right and y grows downwards. For example the line below is drawn with x1="50" y1="40" x2="250" y2="120".

The two windows sit inside one group, <g id="windows">, so a single fill and stroke styles both. The second window reuses the first window's size and is moved with transform="translate(125, 0)".
